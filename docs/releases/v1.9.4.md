# InterAct v1.9.4

修正課堂穩定性問題：

- 隔離 Supabase 即時事件的資料表及場次，避免題目、截圖或場次資料誤入學員名單。
- 學員背景頁暫停心跳、輪詢與非音訊即時連線，返回時重新讀取；結束場次釋放連線，保留歷史資料與下載功能。
- 心跳及學員頁讀取不再重疊堆積；資料庫讀取加入逾時上限。
- 後端異常時，教師仍能關閉本機程式；最多等待四秒。逾時關閉不代表雲端場次已結束，恢復連線後可在管理場次確認。
- 畫面錯誤時提供重新載入、關閉程式按鈕。

本版不修改資料庫結構或 Edge Functions，不需要重新部署後端。學員端請重新整理網頁以載入新版。

隨身碟使用：完整解壓縮 Windows ZIP，將原有 `InterAct.config.json` 放在 `InterAct.exe` 同一資料夾。請勿將私人 API 金鑰放進公開 Release。

Windows 以一般使用者權限執行，未申請管理員權限；公司電腦的安全政策仍可能限制未簽章程式。

測試：TypeScript 編譯、正式網頁建置、既有可攜設定與視窗測試，以及新增離線課堂穩定性回歸測試。
