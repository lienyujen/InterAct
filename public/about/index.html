01 / CLASSROOM

從一張教材，到全班的回應

不用重新製作教材，也能快速發起互動。AI 是協助出題與分析的工具，最後的教學判斷仍由老師掌握。

題

截圖派題與自訂測驗

擷取教材畫面，派送投票、選擇、是非、問答或口語活動。自訂測驗可在出題方向描述題數、題型、對象與難度；學生完成後送出答案。教師可檢視題目、選項並修正正確答案。

寫

電寫與討論板

學生在畫布書寫，也能拍照、上傳或貼上手寫圖片。討論板集中展示全班作品與回應；放大視窗可依課堂設定切換匿名顯示。

拍

全班相機作答

選擇 webcam，在放大的視窗確認取景後拍照。支援手指數量、頭頂大圈／胸前大叉、舉手、站坐與動作，以及 A4 紙文字回答；AI 辨識後由教師確認或修正統計，再發布給全班。

聲

課程錄製、字幕與口譯

按需開啟課程錄製；字幕可獨立顯示或隱藏，並調整語言、大小、粗體與位置。教師另外勾選要派送的即時口譯語音，學生開啟聆聽並選擇可用語言。

也提供彈幕、文字派送、文字雲、抽籤、搶答、匿名回應、Exit Ticket 與課後報表。錄製、字幕與口譯預設關閉；AI 服務依實際使用計費。

DEPLOYMENT / STEP BY STEP

部署 Step by Step：第一次也能完成

這份指南使用 InterAct 桌面版內建的「自動部署」，不需要寫程式，也不需要安裝 Node.js 或 Supabase CLI。已經有後端的人，可直接跳到步驟 8 測試連線；更新後端請從步驟 5 開始。

先準備：Windows／macOS 教師端程式、穩定網路、自己的 Supabase 帳號，以及需要 AI 出題與分析時使用的 Gemini API key。OpenAI 與 Reurl 金鑰為選填。不要把任何私密金鑰或權杖交給學員。

  1. 01

    註冊 Supabase，建立專案

    • 開啟 Supabase Dashboard，註冊或登入自己的帳號。
    • 按 New project，選擇或建立 Organization，輸入專案名稱、設定資料庫密碼，選擇適合的區域後建立。資料庫密碼請自行安全保存，不需貼到 InterAct。
    • 等待專案建立完成、可進入專案後台後再繼續。
    開啟 Supabase Dashboard ↗
  2. 02

    找出專案識別碼與公開金鑰

    • 專案後台 → Project Settings → General，複製 Project ID。也可使用完整網址 https://你的專案識別碼.supabase.co；不是後台的 dashboard/project/... 網址。
    • 到 Settings → API Keys，複製以 sb_publishable_ 開頭的 Publishable key；也可在 Connect 對話框取得專案網址與公開金鑰。
    • 請勿使用 sb_secret_ 或 service_role。Project ID、Publishable key、資料庫密碼與 Access Token 是不同資料，不要混貼。
    Supabase 官方 API 金鑰說明 ↗
  3. 03

    把專案資訊填進 InterAct

    • 開啟 InterAct 桌面版。第一次使用會出現「連接你的 Supabase 專案」；已有設定時，從場次管理開啟「系統設定」。
    • 把 Project ID 或完整專案網址貼進「專案識別碼或網址」，把公開金鑰貼進「Publishable key」。
    • 「學員端網址」非商業用途可留空，程式會使用共用學員端並帶上你的專案資訊；商業使用者依授權自行託管並填入自己的學員網址。首次部署不用自己填「管理金鑰」，稍後會自動產生。
  4. 04

    建立只用於部署的 Access Token

    • 到 Supabase 帳號的 Access Tokens 頁面建立一組權杖。它不是專案的 Publishable key。
    • 優先使用限縮範圍的權杖（scoped／fine-grained token），資源只選這個專案，設定適當到期日。需要資料庫讀寫、Edge Functions 讀寫，以及部署函式 secrets 所需權限；名稱以當時後台顯示為準。
    • 建立後立即複製權杖並安全保存，不要貼在公開文件或截圖中。若 403 提示缺少權限，依 missing_permissions 補足必要權限，重新建立權杖；不必開放所有專案。
    建立 Supabase Access Token ↗ 官方權杖範圍與權限說明 ↗
  5. 05

    展開自動部署，填入所需金鑰

    • 在 InterAct 設定頁展開「還沒建立後端？讓 InterAct 幫你部署」，將上一步的權杖貼進「Supabase 存取權杖」。
    • 在「Gemini API key」貼上自己的金鑰，供 AI 出題、分析與批改使用。不使用 AI 功能可先不填，但相關活動會無法使用。
    • 需要課程錄製、字幕或口譯時，才填「OpenAI API key（選填）」；需要 QR Code 短網址時，才填「Reurl API key（選填）」。私密金鑰會送入自己的 Supabase 後端，不應放進公開設定檔。
    取得 Gemini API key ↗ OpenAI API 金鑰頁 ↗ Reurl ↗
  6. 06

    按「開始自動部署」，等待檢查完成

    • 確認上方的 Project ID 與 Publishable key 均已填入，按「開始自動部署」。請保持程式開啟與網路連線，不要連續重按。
    • 程式依序建立資料表與儲存空間、部署後端函式、設定 API 金鑰、產生管理金鑰，最後檢查部署結果與學生端讀取權限。
    • 成功時會出現「後端部署完成，測試連線後即可儲存。」若某步失敗，先查看該步的錯誤、修正再重跑；不要為了重試刪除專案或課堂資料。瀏覽器版無法執行此自動部署，請使用桌面版。
  7. 07

    備份教師管理金鑰

    • 部署完成後，「管理金鑰」欄位會顯示自動產生的值。按「複製」，存到自己的安全位置。
    • 這把金鑰用來開課與管理場次，不是給學生使用的公開金鑰。換電腦時，在同一專案設定中貼上同一組。
    • 不要任意按重新產生管理金鑰；換發後其他電腦的舊金鑰會失效。更新程式時保留自己原有的管理金鑰與公開設定。
  8. 08

    測試連線，儲存並開課

    • 按「測試連線」，確認顯示「連線成功，可以儲存了。」再按「儲存並開始使用」。
    • 程式重新載入設定後，建立一個測試場次。用另一台手機掃 QR Code 加入，先派送一則文字或簡單題目，確認老師與學生畫面都能更新。
    • 需要 AI 時再測一次出題／分析；需要字幕與口譯時再分別開啟測試。只測連線不代表 AI 帳號與額度也已驗證。
  9. 09

    更新版本或帶到另一台電腦

    • 更新教師端後，使用同一個 Supabase 專案，從系統設定再跑一次自動部署，補齊新版後端。既有專案的操作前，建議先備份重要課堂資料。
    • 重新部署時，空白的 AI 金鑰欄位不會刪除後端既有金鑰；要替換金鑰才填入新的值。部署成功會清空這次輸入的 Access Token。
    • 隨身資料夾保留 .env 或 InterAct.config.json（只含公開設定），新電腦另外輸入教師管理金鑰。不要把 Access Token 或 AI 私密金鑰放在隨身公開設定中。

卡在哪一步？先看這裡

401／權杖無效或過期

確認使用 Access Token，而不是 Publishable key。回 Access Tokens 建立有效權杖再貼上。

403／權限不足

確認權杖包含此專案，並有失敗步驟所需的資料庫、函式或 secrets 權限。組織成員自身也必須有相應權限。

找不到專案／識別碼格式錯誤

使用 Project ID 或 https://專案識別碼.supabase.co，不要填後台頁面的網址。

資料表不存在／學生端讀不到

先完成全部自動部署步驟，確認 Publishable key 屬於同一專案，再測試連線；不要改用 secret key，也不要關掉權限保護來繞過錯誤。

Function failed to start／AI 無法出題

確認教師端為新版，重新部署對應後端。仍失敗時查看 Supabase Edge Functions 的 Logs；AI 的服務異常、金鑰或額度問題需另外確認。

沒有自動部署功能

請在 Windows／macOS 教師桌面程式操作，網頁版不提供自動部署。

02 / GET STARTED

第一次使用，跟著這六步走

先連接自己的 Supabase 專案，再開始課堂。教學與授權頁可直接閱讀，不需要 GitHub 帳號。

  1. 01

    取得教師端程式

    下載適合的 Windows 或 macOS 版本。Windows 解壓縮後執行資料夾內的 EXE；macOS 開啟 DMG 並安裝 App。學員不必安裝程式。

  2. 02

    註冊並建立 Supabase 專案

    前往 Supabase 網站建立帳號與專案。在程式的部署／設定頁填入專案網址或識別碼、公開 publishable key，再依部署精靈提示設定後端與所需的 AI 金鑰。保留教師管理金鑰，不要給學生。

  3. 03

    建立場次，邀請學員加入

    輸入課程名稱並建立新場次，顯示 QR Code。學員用瀏覽器掃碼加入、填入姓名。需要隱藏姓名時，開啟主選單的匿名設定。

  4. 04

    選擇活動與派送方式

    截圖派題後選擇題型；自訂測驗在出題方向描述需求後派送。AI 出題時請等待生成完成。相機作答會開啟全班姿態回應視窗，先選相機與回應方式，再拍照、確認統計並發布。

  5. 05

    查看作答與按需使用 AI

    教師可放大題目與選項、修正答案並查看學員結果。選擇／是非等客觀題依答案判分；自訂測驗的主觀題由 AI 批改。其他完整分析依教師操作啟用，不需每題都分析。字幕與口譯另在設定及主選單控制。

  6. 06

    下課、整理並匯出

    按下「下課並產生報告」，檢視學員回應及分析並匯出 Excel。若課程錄製取得逐字稿，可整理課堂重點；學員收到重點整理，不是整份逐字稿。沒有錄製內容時不生成該項重點。

隨身碟帶走程式，也帶走公開設定

把 .env 或 InterAct.config.json 放在程式同一資料夾，macOS 放在 App 外部的同一資料夾。複製整個資料夾時保留自己的設定檔。新電腦的教師管理金鑰仍需另外設定。

設定檔只放 Supabase 網址、公開金鑰與學員端網址。Gemini、OpenAI 私密 API 金鑰保存在後端，切勿放入公開網頁、隨身設定或 GitHub。範例請替換成自己的公開設定。

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
VITE_PUBLIC_APP_URL=https://join.ehuayu.org

前往 Supabase 註冊／建立專案 · 取得 InterAct 教師端版本

學員需要安裝 App 嗎？

不需要。使用手機、平板或電腦瀏覽器掃碼加入即可。

沒有平板，可以全班作答嗎？

可以使用全班相機作答。先說明姿態與答案的對應方式，再拍照辨識；教師確認統計後發布。A4 紙回答需確保字夠大、光線充足且沒有遮擋。

相機會做人臉身分辨識嗎？

全班姿態功能不做人臉身分辨識，送出指定照片給 AI 分析可見姿態或紙上文字。拍攝前請依學校規範告知並取得所需同意，避免拍到不必要的個人資訊。

字幕、口譯會自動開始扣費嗎？

相關功能預設關閉，由教師決定是否開啟。隱藏字幕不等於停止課程錄製；只要音訊仍送往 AI，仍可能產生費用。不使用時請停止錄製並關閉口譯。

AI 答案或統計錯了怎麼辦？

先由教師檢視。題目答案與相機統計可依畫面提供的功能修正；AI 結果不應取代教師判斷。
