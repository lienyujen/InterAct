01 / CLASSROOM

Turn existing materials into participation

Start an activity without rebuilding your materials. AI assists with questions and analysis; teachers remain in control.

Q

Screenshot questions & custom quizzes

Send polls, multiple-choice, true/false, short-answer or speaking activities. Describe quiz length, types, audience and difficulty in a prompt. Teachers can review questions and options and correct answer keys.

W

Handwriting & discussion boards

Learners draw, take a photo, upload or paste handwriting images. Display class responses on the discussion board; the enlarged view supports anonymous display.

C

Whole-class camera responses

Choose a webcam and inspect the enlarged preview before capture. Count fingers, overhead circles/chest crosses, raised hands, standing/sitting or movements; read answers on A4 paper. Review and correct AI counts before publishing.

A

Recording, captions & interpretation

Enable course recording only when needed. Separately show or hide captions and set language, size, weight and position. Teachers select interpretation audio languages; learners start listening and choose an available language.

Also includes live comments, text delivery, word clouds, random selection, buzzers, anonymous responses, Exit Tickets and reports. Recording, captions and interpretation are off by default; AI usage is billed separately.

DEPLOYMENT / STEP BY STEP

Deployment, step by step

Use the teacher desktop app’s built-in deployment wizard—no coding, Node.js or Supabase CLI required. For an existing backend, go to step 8 to test it; start at step 5 to update it.

Prepare the Windows/macOS teacher app, an internet connection, your own Supabase account and a Gemini API key if using AI questions or analysis. OpenAI and Reurl keys are optional. Keep private keys and tokens away from learners.

  1. 01

    Create your Supabase project

    • Sign up or sign in to the Supabase Dashboard.
    • Choose New project, select or create an organization, set a project name and database password, select a suitable region and create it. Save the password securely; it is not an InterAct input.
    • Wait until the project is ready and its dashboard is accessible.
    Supabase Dashboard ↗
  2. 02

    Copy the project ID and public key

    • Find Project ID in Project Settings → General. Alternatively use https://YOUR_PROJECT.supabase.co, not the dashboard/project/... URL.
    • Copy the sb_publishable_ key from Settings → API Keys, or get the URL and public key from Connect.
    • Never use sb_secret_ or service_role here. The project ID, publishable key, database password and access token are different values.
    Official API-key guide ↗
  3. 03

    Fill in InterAct’s connection settings

    • Open the teacher desktop app. First use shows connection setup; otherwise open system settings from session management.
    • Fill in the project ID or URL and Publishable key.
    • For noncommercial use, the learner URL can remain blank to use the shared frontend. Commercial users should host their own under the license terms. Leave the management key blank on a first deployment; the wizard generates it.
  4. 04

    Create a deployment access token

    • Create an Access Token in your Supabase account. It is not the project’s public key.
    • Prefer a scoped token for this project only, with an appropriate expiry. Allow database read/write, Edge Functions read/write and the permission needed to deploy function secrets.
    • Copy and secure the token when created. If a 403 lists missing_permissions, create a replacement with the necessary permissions, not access to every project.
    Access Tokens ↗ Official scoped-token guide ↗
  5. 05

    Open automatic deployment and provide keys

    • Expand the setup section offering backend deployment and paste the Supabase access token.
    • Supply your Gemini API key for AI questions, analysis and grading. Without it, those features cannot work.
    • Only provide an OpenAI key when using recording/captions/interpretation, and a Reurl key when using short QR URLs. Private keys belong in your backend, not portable public configuration.
    Gemini keys ↗ OpenAI keys ↗ Reurl ↗
  6. 06

    Start deployment and wait for verification

    • Make sure the project ID and public key are filled, then start automatic deployment. Keep the app open and connected; do not repeatedly click.
    • The wizard creates tables and storage, deploys functions, configures secrets, generates the management key and checks backend and learner access.
    • Wait for the completion message. On failure, inspect the failed step before retrying; do not delete the project or class data. Automatic deployment is desktop-only.
  7. 07

    Securely save the management key

    • Copy the generated management key to a safe location.
    • It authorizes teachers to create and manage sessions. Learners must not receive it. Use the same key on your other computers.
    • Regenerating it invalidates the old key on other computers. Preserve the existing key when updating.
  8. 08

    Test, save and run a trial session

    • Test the connection, then save when the success message appears.
    • Create a test session and join by QR code from another device. Deliver a text message or simple question and check both screens.
    • Test AI generation separately, then captions and interpretation if needed. A connection test does not verify AI credentials or quota.
  9. 09

    Update or move to another computer

    • After updating the app, run deployment again against the same project to update its backend. Back up important class data before maintenance.
    • Blank AI-key inputs preserve existing backend keys. Enter new values only when replacing them. A successful deployment clears the entered access token.
    • Carry .env or InterAct.config.json containing only public settings; enter the teacher management key separately on the new computer. Never include access tokens or AI private keys in public portable settings.

Troubleshooting

401 / invalid token

Use a valid account Access Token, not a publishable key. Create a replacement if expired.

403 / insufficient permissions

Check project scope and the failed step’s database, function or secret permissions. Your account role must also allow the operation.

Project not found

Use Project ID or https://YOUR_PROJECT.supabase.co, not the Dashboard URL.

Missing tables / learner access fails

Complete deployment and confirm the public key belongs to the same project. Do not substitute a secret key or disable access protection.

Function fails to start / AI generation fails

Update the teacher app and redeploy the backend. Inspect Edge Function logs if it persists; check AI credentials, quota and provider availability separately.

Deployment unavailable

Use the Windows/macOS teacher desktop app, not the browser frontend.

02 / GET STARTED

Your first lesson in six steps

Connect your own Supabase project before teaching. This guide and license are public—no GitHub account needed.

  1. 01

    Get the teacher application

    Download the Windows or macOS edition. On Windows, extract the archive and run the EXE. On macOS, open the DMG and install the App. Learners only need a browser.

  2. 02

    Create a Supabase account and project

    Visit Supabase, sign up and create a project. Enter its URL or identifier and public publishable key in setup. Follow the deployment wizard to configure the backend and AI keys. Keep the teacher management key private.

  3. 03

    Create a session and invite learners

    Name the session and display its QR code. Learners scan it and enter their names. Enable anonymity in the main menu when names should be hidden.

  4. 04

    Choose and deliver an activity

    Capture materials and select a question type, or describe a custom quiz. Wait for AI generation to finish. For camera responses, select the camera and response scheme, capture, review counts and publish.

  5. 05

    Review answers and use AI when needed

    Enlarge questions, inspect options, correct keys and view learner results. Objective items are scored against keys; subjective custom-quiz items use AI grading. Other full analysis is teacher-triggered. Control captions and interpretation separately.

  6. 06

    End the session and export

    End the lesson, review results and export Excel reports. If recording produced a transcript, summarize lesson highlights for learners rather than sending a verbatim transcript. Without recorded content, that summary is not generated.

Take public settings with the application

Keep .env or InterAct.config.json beside the program; on macOS, keep it outside the App in the same folder. Copy the whole folder and preserve your settings when updating. Set the teacher management key separately on a new computer.

Only store the Supabase URL, public key and learner URL here. Private Gemini/OpenAI API keys belong in the backend, never in public pages, portable settings or GitHub. Replace the placeholders with your own public configuration.

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
VITE_PUBLIC_APP_URL=https://join.ehuayu.org

Open Supabase to sign up / create a project · Get the InterAct teacher application

Common questions

Do learners need an app?

No. They join using a phone, tablet or computer browser.

Can a class respond without tablets?

Use whole-class camera responses. Explain the gesture-to-answer mapping first, then capture and review before publishing. Paper answers need large writing, good lighting and an unobstructed view.

Does camera response identify faces?

It does not perform facial identity recognition. The selected image is sent to AI to analyze visible responses or paper text. Follow your institution’s consent and privacy requirements before capture.

Does hiding captions stop billing?

No. Recording and interpretation are off by default, but hiding captions does not stop active recording. Audio sent to AI can still incur charges. Stop recording and interpretation when not needed.

What if AI is wrong?

Teachers should inspect outputs and use the available answer-key or camera-count correction controls. AI does not replace teacher judgment.
